# Watching Water Boil

An interactive constant-pressure boiling experiment for H₂O, for ES 305 Thermodynamics at Embry-Riddle Aeronautical University.

A piston-cylinder vessel animates alongside a live-traced T–v diagram through compressed liquid, saturated liquid, the two-phase dome (with quality *x*), saturated vapor, and superheated vapor, at a choice of three pressures shown together against the full saturation dome.

## Live experiment

[Open Watching Water Boil](https://nuhaaljuneidi.github.io/watching-water-boil/)

## What students investigate

- How specific volume changes during constant-pressure heating.
- Where compressed liquid, saturated mixture, and superheated vapor appear on a T–v diagram.
- How vapor quality describes a two-phase mixture.
- How pressure shifts the saturation temperature and the path across the dome.

## Suggested activity

1. Select a pressure and predict the saturation temperature.
2. Advance the heating process and identify each thermodynamic region.
3. Pause inside the dome and interpret the displayed quality.
4. Repeat at another pressure and compare the two paths.
5. Explain which properties change continuously and which identify a phase boundary.

## Run locally

Open `index.html` in a modern browser. The experiment is a self-contained HTML application with no build step.
